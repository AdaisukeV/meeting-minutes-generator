# 変更記録メモ(`docs/memo/`)

`CLAUDE.md` 5章に従い、以下の変更を行った場合はこのディレクトリにファイルを追加して記録する。

- コメントアウト(処理を残したまま無効化した箇所とその理由)
- 処理の削除(削除したファイル・関数と、削除して問題ない根拠)
- ライブラリ(依存パッケージ)の変更
- 運用時プロンプト(`projects/*/prompts/`)の入出力契約の変更(上記3種には該当しないが、非対話実行の挙動を左右するため追跡する)

## ファイル命名

`YYYY-MM-DD-<短い英語スラッグ>.md`(例:`2026-08-16-add-dependencies.md`)

## 記載項目

| 項目 | 内容 |
|---|---|
| 日付 | 変更した日 |
| 分類 | コメントアウト / 処理削除 / 依存変更 / プロンプト契約変更 |
| 対象 | ファイル・パッケージ名 |
| 内容 | 何をどう変えたか |
| 理由 | なぜ必要だったか |
| 影響・代替 | 影響範囲、元に戻す手順や代替手段 |
